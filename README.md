# 🐍 深海贪吃蛇 - 未来科技版

## 游戏介绍

一款以未来科技风格打造的深海主题贪吃蛇游戏，融合了炫酷的视觉效果和丰富的游戏机制。

## ✨ 核心特性

### 1. 🌊 深海主题背景
- 渐变深海蓝色背景
- 动态气泡上升动画
- 沉浸式海底氛围

### 2. 🎨 未来科技风格
- 霓虹灯效果UI设计
- 发光边框和阴影
- 科技感十足的配色方案

### 3. 🌈 变色贪吃蛇
- 每吃一个食物变换一次颜色
- 10种霓虹色彩循环
- 蛇身渐变效果

### 4. 🎮 游戏难度
- 初始速度适中，适合上手
- 吃食物后速度逐渐加快
- 最高速度有上限，保证可玩性

### 5. 💎 特殊道具系统
- 金色菱形道具随机出现
- 吃到后额外增加3节长度
- 道具8秒后自动消失

### 6. 📊 分数系统
- 普通食物：+10分
- 金色道具：+30分
- 本地存储最高分记录

## 🎯 操作说明

| 按键 | 功能 |
|------|------|
| ↑ / W | 向上移动 |
| ↓ / S | 向下移动 |
| ← / A | 向左移动 |
| → / D | 向右移动 |
| 空格键 | 暂停/继续 |

## 🚀 启动方式

1. 直接在浏览器中打开 `index.html` 文件
2. 点击"开始游戏"按钮
3. 使用方向键或WASD控制贪吃蛇

## 🛠️ 技术栈

- HTML5 Canvas
- CSS3 动画
- 原生 JavaScript (ES6+)
- LocalStorage 本地存储
